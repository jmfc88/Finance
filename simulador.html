Sincronización entre dispositivos (opcional)

Sin esto, tu historial se queda solo en este navegador/dispositivo. Con un token configurado, cada operación que registres se guarda también en tu repo de GitHub, y cualquier otro dispositivo (PC, móvil...) la verá igual.
¿Cómo creo el token? (una vez, 2 minutos)
1. Ve a github.com/settings/personal-access-tokens/new (te pedirá iniciar sesión si no lo has hecho).
2. En "Repository access" elige "Only select repositories" → selecciona Finance.
3. En "Permissions" → "Repository permissions" → busca "Contents" → cámbialo a "Read and write".
4. Baja del todo y pulsa "Generate token".
5. Copia el token (empieza por "github_pat_...") y pégalo aquí arriba — GitHub solo te lo enseña una vez.
Para revocarlo en cualquier momento: misma página de "Fine-grained tokens" → tu token → "Delete".
